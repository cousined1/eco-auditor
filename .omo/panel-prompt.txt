## P0-01 — /login and /signup resolve to homepage content for non-JS clients
**Root cause (two layers):**
- `scripts/prerender.mjs:37-47` `ROUTES` array = `['/','/pricing','/methodology','/sample-report','/security','/contact','/privacy','/terms','/dpa']` — `/login` and `/signup` are NOT prerendered, so no `static/login/index.html` / `static/signup/index.html` exists. Comment `:34-36` says app routes are intentionally excluded, but /login & /signup are public auth pages, not /app/*.
- `server.cjs:1542-1545` SPA fallback `app.get('*', (_req,res) => res.sendFile(path.join(__dirname,'static','index.html')))` serves the **homepage** prerender for any unmatched route → non-JS client (curl, crawler) hitting /login or /signup receives homepage HTML.
- React Router wiring IS correct (`App.tsx:275-276` `/signup`→Signup, `/login`→Login). `Login.tsx` and `Signup.tsx` are real auth screens (email/password + Google/Azure/Apple OAuth). The bug is purely the prerender/server layer.

**Fix:** Add `/login` and `/signup` to `prerender.mjs` ROUTES with a per-route `<meta name="robots" content="noindex,nofollow">` injected into the prerendered HTML head; add them to `server.cjs` `PRERENDERED_ROUTES` (`:1523-1526`) so they map to their own static file before the SPA fallback. Ensure SSR output for these routes is the auth form (the components are self-contained, no InsForge top-level calls, so `render()` works). Keep them OUT of `public/sitemap.xml` and ensure `robots.txt` disallows them. Add plan-aware signup: `Signup.tsx` reads `?plan=starter&billing=annual&source=pricing` from `useSearchParams`, preselects plan, passes through to post-signup checkout redirect. Add `noindex,nofollow` meta to both auth components (also set client-side via useEffect for the hydrated path). Distinct error messages already mostly present (`Login.tsx:32`, `Signup.tsx:36`).

**Failable check:** `node scripts/prerender.mjs` then `grep -l "noindex" static/login/index.html static/signup/index.html` (both match); `curl -s $URL/login | grep -i "sign in"` returns the auth form h1, NOT homepage content; `curl -s $URL/login | grep -i "Start your free trial"` should NOT match homepage hero copy.
